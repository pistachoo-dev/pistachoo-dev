## 🥜 About me

I'm **Pistacho**, a developer from Spain who builds **practical software that saves businesses time and money**.

My focus is on **Python automation, AI integrations and backend development**. I like turning messy, repetitive processes into clean, reliable tools, and I care about writing code that is **readable, tested and easy to maintain**.

- 🤖 Building **AI-powered chatbots and assistants** that answer from your own documents
- ⚙️ Automating repetitive work: **emails, invoices, spreadsheets, reports**
- 🗄️ Designing **databases and REST APIs** with Python, Java and MySQL
- 🧠 Using modern **AI-assisted development** workflows to deliver faster without cutting corners
- 🌍 Working in **English and Spanish**
